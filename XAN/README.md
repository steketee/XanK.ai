# XAN - XanK.ai Teaching Bot

This folder is for **Xan** (14).

## How to install / use on iPhone

1. Open this page in Safari on iPhone.
2. Tap the Share button.
3. Tap "Add to Home Screen".
4. Name it "XanK - Xan" and add.

The app icon will appear. Tap it to open the teaching chatbot for school, library, and day help.
